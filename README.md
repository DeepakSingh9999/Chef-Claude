# 🍳 Chef Claude

This project is a fun and interactive **recipe generator** built with **React** and powered by the **Chef Claude API**.

---

## 🚀 How It Works
1. Provide a set of random ingredients.  
2. These ingredients are sent to the **Chef Claude API**.  
3. Chef Claude responds with a creative recipe suggestion that uses those ingredients.  
4. The recipe (title, steps, and description) is displayed in the React frontend.

## ✨ Features
- 🎲 Random ingredient generator for unique recipe prompts  
- 🤖 API integration with Chef Claude for AI-powered recipe creation  
- ⚛️ React-based UI for dynamic recipe display  
- 🍴 Simple and engaging way to discover new cooking ideas  

---

## 🛠️ Tech Stack
- **React** – Frontend framework  
- **Chef Claude API** – AI-powered recipe generation  
- **JavaScript (ES6+)** – Core logic and API handling  
- **CSS** – Styling for clean and responsive design  

---

## 🎯 Purpose
This project demonstrates React frontend development, API integration, and AI-based creative applications. It’s both a learning exercise and a fun way to explore AI in the kitchen.
